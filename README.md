# Mounesh Chandra M — Developer Portfolio

A responsive, single-page developer portfolio built with HTML, CSS, and vanilla JavaScript. The galaxy background is the exact SciTechDaily image supplied by the portfolio owner, displayed with contain sizing to avoid cropping and rotating slowly behind animated stars and shooting stars. Five colorful planets orbit the hero illustration and can be dragged. Navigation buttons open panels for About, Technical Toolkit, Projects, and Experience & Education; the dedicated contact screen opens a prefilled Gmail draft from its message form.

The latest resume is included as `Mounesh-Chandra-Resume.pdf` and is available to download from the header, hero, and footer. With reduced motion enabled, the galaxy and planetary animations are disabled.

## Image credits
- Galaxy background image: SciTechDaily.com, from [“The Center of Our Galaxy May Not Be a Black Hole”](https://scitechdaily.com/the-center-of-our-galaxy-may-not-be-a-black-hole/). Used with permission from the portfolio owner.

## Run locally
1. Extract this folder.
2. Open it in Visual Studio Code.
3. Install the Live Server extension, then right-click `index.html` and select **Open with Live Server**.

No build step or package installation is required. Google Fonts are loaded over the internet; system fallbacks are provided.

## Personalize before publishing
- In `index.html`, update your introduction and social links if needed. Replace `Mounesh-Chandra-Resume.pdf` when updating the downloadable resume.
- The contact form opens a Gmail compose draft; visitors need to review and send the message in Gmail.
- In `script.js`, update project descriptions and replace the general GitHub profile links with individual repository URLs when available.
- Keep private information such as home address and date of birth off the public website.

## Publish
Upload the extracted `mounesh-portfolio` folder to Netlify, or push it to GitHub and connect the repository to Netlify. Preview on desktop and mobile before sharing the public URL.
